# 팬텀 힘 유지 실험 프로토콜 — 8개 대역 × 500 mL 교란 3회

2026-09-03 작성. 이 실험이 검증하는 것은 두 가지다.

1. **미소 지령 실행 수정.** 2026-09-03 이전에는 서보의 idle 문턱
   (`IDLE_VEL_EPS_RAD_S = 1e-3 rad/s`)이 힘 조절기의 수렴 지령을 전부 "정지 의도"
   로 버렸다 — A_t0p5_r1 실측에서 조절기가 18 초 동안 전진을 지령하는데 팁이
   2 µm 만 움직였고, 힘이 목표 아래 0.1~0.3 N 에서 영원히 정체했다. 수정 후에는
   접촉 프로빙 중 서보가 의도를 추측하지 않는다 (`probing_mode` 구독 →
   `JointCommandLimiter.step(..., explicit_intent=True)`). 이 실험이 그 수정의
   첫 팬텀 검증이다.
2. **대역별 유지·교란 응답.** 0.5 ~ 4.0 N 여덟 대역에서 500 mL 교란(주입/회수
   각 3회)에 대한 힘 응답과 **로봇 변위**를 함께 기록한다. 힘이 돌아온 것이
   로봇이 받아 낸 것인지 팬텀이 스스로 누운 것인지는 변위 없이는 못 가른다.

| 항목 | 값 |
|---|---|
| 목표 대역 | 0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0 N |
| 교란 | 500 mL 주입 3회 + 회수 3회, 대역마다 |
| 유지 구간 | 대역마다 30 s (교란 전, 정착 기준선) |
| 진입 문턱 | 목표 − 0.1 N (스크립트가 자동 설정) |
| 이탈 문턱 / 밴드 | 0.10 N / 0.05 N (스크립트가 자동 설정) |
| 캡처 위치 | `runs_sweep500/` (예전 실행과 분리) |

### 대조군을 함께 받는다 (`--placebo`) ✅ 2026-09-04

```bash
./run_repeat.sh 2 --placebo --targets "0.5 1.0 1.5 2.0 2.5 3.0 3.5 4.0" \
                  --step-ml 500 --settle-s 180 --out-dir runs_lap2
```

대역마다 교란을 **두 번** 받는다.

| 캡처 | 힘 유지 | 무엇을 재는가 |
|---|---|---|
| `A_…` | 켬 | 교란 없는 유지 30 s |
| `B_…` | 켬 | 같은 주사기 조작을 제어가 받아낸 결과 |
| `C_…` | **끔** | 같은 주사기 조작이 **제어 없이** 만드는 힘 |

C 가 이 회차의 요점이다. B 만 있으면 "힘이 목표 근처에 머물렀다" 가 제어 덕분인지
교란이 애초에 그 정도였을 뿐인지 구별되지 않는다. 지금까지 그 반사실은 팬텀 강성을
곱해 외삽했고(`fh/analysis.py` 의 `regulation_evidence`, 비선형이면 외삽한 만큼
틀린다), C 는 같은 자리에서 그것을 **직접 잰다.**

C 에서 로봇은 접촉 자세 그대로 z 를 놓는다. 접촉 모드도 속도 상한도 그대로다.
스크립트가 캡처 앞뒤로 `contact_control.force_hold_enabled` 를 끄고 되돌리며,
값이 실제로 바뀐 것을 확인하고 넘어간다 — 되돌리기에 실패하면 그 자리에서 멈춘다.
꺼진 채 다음 대역에 들어가면 그 대역이 통째로 대조군이 되는데, 파일만 봐서는
알기 어렵기 때문이다 (그래서 캡처 메타에도 `force_hold_enabled` 가 함께 적힌다).

⚠️ **안전층은 대조군에서도 살아 있다.** `safety.max_contact_force_n` 를 넘으면
제어를 껐어도 후퇴한다. 물을 넣는 것은 조작자가 아니라 주사기이므로, 손을 대지
않아도 힘은 오를 수 있다. C 를 받는 동안 **한계에 닿으면 주입을 멈춘다** — 후퇴가
시작되면 그 사건은 더 이상 개루프가 아니다.

C 는 B 뒤에 온다. C 가 끝나면 프로브가 목표에서 밀려나 있을 수 있고, 그 상태에서
B 를 받으면 두 팔의 출발점이 달라진다.

### 조작자가 할 일

1. 첫 대역에서 "접촉 대기" 가 뜨면 스타일러스로 프로브를 팬텀에 누른다.
   진입하면 로봇이 z 를 잡는다. **이후 세션 끝까지 프로브를 떼지 않는다.**
2. 교란 캡처마다 **500 mL 주입 3회 + 회수 3회**:

   | 키 | 뜻 |
   |---|---|
   | `i` | 주입 시작 순간 |
   | `w` | 회수 시작 순간 |
   | `s` | 표면 안정됨 |
   | `u` | 마지막 표시 취소 |
   | `q` | 캡처 종료 (6회 끝난 뒤) |

3. 대역 전환·정착 대기는 스크립트가 한다. 조작자는 주사기와 키만.

### 수정 검증 포인트 (첫 대역에서 바로 확인)

- 서보 로그(터미널 1)에 **"접촉 프로빙 진입 — 미소 관절 지령을 그대로 실행한다"**
  가 찍힌다.
- 힘이 목표에 **도달**한다 — 0.5 N 대역에서 0.50 ± 0.05 N (수정 전엔 0.41 정체).
- 유지 30 s 동안 팬텀 이완을 쫓는다 — 힘이 흘러내리지 않는다 (수정 전엔
  0.49 → 0.38 N 하락).
- **불합격 모드 — 목표 주위에서 떨면(hunting):** 강성 대비 게인 문제다.
  **`admittance_b_z` 를 올린다. deadband 는 이 문제의 손잡이가 아니다.**

  ```bash
  ros2 param set /us_diff_ik_node contact_control.admittance_b_z 4000.0
  ```

  값을 바꿨으면 보고서에 적는다 — 캡처 메타가 라이브 값을 읽으므로 기록은 남는다.

  🔁 2026-09-04 에 순서를 뒤집었다. 예전에는 deadband 0.15 를 1차로 적었는데,
  한계주기는 밴드 폭이 아니라 **루프 이득**이 만든다. 밴드를 넓히면 진동은 그대로
  둔 채 정착 지점만 목표에서 멀어지고, 게다가 0.15 > wait_settled 의 허용오차
  0.08 이라 **정착 판정이 원리적으로 불가능**해진다 — 고치는 대신 측정을 망가뜨린다.

  근거 (runs_sweep500, 2026-09-04): 유지 구간이 전 대역에서 주기 8~9.4 s ·
  ±0.35 N 으로 돌았고, 힘이 압입을 1.5~2.4 s 뒤따랐다. 여기서 접촉 강성
  k_c = 0.28 N/mm (0.5 N) … 0.66~0.71 (1.5~2.0 N) 이 나온다. 한계주기 주파수
  ω = 0.74 rad/s 에서 개루프 이득은 |L| = k_c/(B_z·ω) = 0.89 — **경계 위**다.
  그래서 B_z 배포값을 1000 → 3000 으로 올렸다 (probe.yaml). 위 명령은 그래도
  떨 때 한 단계 더 올리는 것이다.

  ⚠️ B_z 를 올리면 접근이 그만큼 느려진다. `--settle-s` 도 함께 늘려라.

### 예상되는 두 가지 — 사고 아님

- **0.5 N + 500 mL 회수**: 힘이 이탈 문턱(0.10 N) 아래로 떨어져 접근 모드로
  복귀할 수 있다. 스크립트가 멈추며 이어서 돌릴 명령을 그대로 출력한다 —
  다시 누르고 그 명령을 붙여넣는다. 이것 자체가 저대역의 소견이다.
- **4.0 N + 500 mL 주입**: 피크가 경고(4.5 N)를 넘고 한계(5.0 N)에 근접할 수
  있다. 경고 이상 전진 금지·5 N 강제 후퇴가 개입하는 것이 정상 동작이고, 전부
  기록되어 안전 표에 남는다. 조작자는 놀라지 말 것.

## 안전 메모

접촉 프로빙 중에는 데드맨을 놓아도 힘 유지가 계속되는 것이 설계다. 급히 빼야
하면:

1. 주사기 회수로 힘을 이탈 문턱 아래로 → 접근 모드 복귀 → 데드맨 해제
   (워치독 후퇴 −z, 5 mm/s)
2. 그래도 안 되면 티치펜던트 **E-stop**

힘 한계 5 N(‖F‖)은 팬텀에서 도달 가능한 값으로 잡혀 있고, 초과 시 강제 후퇴
(5 mm/s)가 조절기 안에서 걸린다. 이 층은 교정·모드와 무관하게 산다.
