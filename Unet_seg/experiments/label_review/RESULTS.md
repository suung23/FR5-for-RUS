# 수동 라벨 수정 + 필터 재학습 — 결과 (2026-08-26)

고정 테스트셋: **16환자 / 2,017프레임**, 수정 GT(P097 포함) 기준. 모든 런이
같은 프레임·같은 정답 위에서 채점됐다. 집계는 프레임 → 환자평균 → 환자간 평균,
신뢰구간은 **환자 단위** 부트스트랩(4,000회, seed 42).

## 0. 무엇이 바뀌었나

| 데이터 변경 | 적용 범위 |
|---|---|
| 수동 편집 라벨 (P033 145/188, P034 157/158, P097 73/73) | train 2명 + test 1명 |
| 편집기가 안 건드린 44프레임 제거 | train |
| manual 배제 (VERDICTS `label_wrong`) | **train 4명 + val 1명만** — test 4명은 보호 |
| hydro 면적 필터 (0.022888) | train 78→50명, val 16→9명 |

test 를 보호한 이유: VERDICTS 불량 9명 중 4명(P000 P020 P021 P043)이 test 에 있고,
그 4명이 곧 최하위 점수 환자들이다. 빼면 예측이 하나도 안 바뀌어도 헤드라인이 오른다.

## 1. 체크포인트 선택이 대부분의 효과보다 크다 — 먼저 읽을 것

`val_dice` 최고점이 epoch 1~9 사이에서 잡히고, 그 뒤 30여 epoch 은 과적합이다.
어느 epoch 이 뽑히느냐가 테스트 점수를 좌우한다. 그래서 모든 런을 **두 체크포인트**로
보고한다: `best.pt`(val 선택)와 `last.pt`(epoch 40 고정).

| 런 | 선택 epoch | best.pt | last.pt | 차 |
|---|---|---|---|---|
| base (seed 42) | 7 | 0.7485 | 0.7352 | 0.013 |
| seed 43 (라벨 동일) | 5 | 0.7446 | 0.7315 | 0.013 |
| edit | 3 | 0.7489 | 0.7416 | 0.007 |
| edit_noP033 | 1 | 0.7167 | 0.7486 | **0.032** |
| **edit_man** | 9 | **0.7643** | **0.7667** | 0.002 |
| edit_man_hydro | 4 | 0.7006 | 0.6737 | 0.027 |

`edit_noP033` 은 best.pt 에서 꼴찌, last.pt 에서 2등이다. epoch 1 체크포인트가
뽑힌 결과일 뿐이므로 **P033 편집의 효과에 대해 이 실험은 아무 말도 하지 못한다.**

## 2. 짝지은 델타 (같은 test, 같은 환자)

| 비교 | best.pt | last.pt | 판정 |
|---|---|---|---|
| 재현성 바닥 (seed 42→43) | −0.0038 [−0.021, +0.009] | −0.0036 [−0.040, +0.034] | 노이즈 바닥 |
| 수정 라벨 재학습 | +0.0004 [−0.028, +0.029] | +0.0065 [−0.022, +0.035] | 측정 불가 |

| **+ manual 배제** | +0.0154 [−0.015, +0.045] 11/16 | **+0.0250 [+0.005, +0.060] 14/16** | **일관되게 개선** |

방향이 뒤집히지 않는 유일한 개선이다.

배제 코호트(test 4명 제외, 12명) 기준: base 0.8129 → **edit_man 0.8295**,
edit_man_hydro 0.7776.

## 3. 라벨 수정 자체의 검증 — 모델과 무관

`dataset_audit/label_appearance.frame_stats` 를 같은 프레임에 원본/편집만 바꿔 적용
(`verify_edited_appearance.py`). contrast = 주변 링 − 라벨 내부, 클수록 내강.

| 환자 | contrast | 판정 |
|---|---|---|
| P034 | 22.3 → 30.4 (+8.1) | 개선 |
| P097 | 31.2 → 40.8 (+9.5) | 개선 |
| P033 | 15.9 → 11.0 (**−4.9**) | 145프레임 중 76개 악화, f73~f108 구간에 집중 |

P033 의 해당 구간은 편집 윤곽이 무에코 코어 **바깥**으로 나가 있다. 원본이 과포함이라
깎아야 하는데 넓힌 셈이다. f145/f156/f187 등은 반대로 +13 개선이라, P033 은
"전체 불량"이 아니라 **구간별로 갈린다**. 사용자 지시에 따라 편집본을 그대로 사용했다.

## 4. 기존 모델이 잘못된 라벨을 재현하고 있었다

체크포인트를 바꾸지 않고 GT 만 교체:

    P097   원본 GT 0.8502  →  수정 GT 0.7852   (−0.065)

나머지 15명은 변동 없음. 감사 문서(final_summary.md §4)가 기대한 "모델이 GT보다 낫다"의
**반대 방향**이다. 과포함 라벨로 학습했으니 과포함을 재현한다.

## 5. 결론

1. **manual 배제가 유일하게 작동하는 지렛대다.** train 4명 + val 1명을 빼는 것만으로
   두 선택 기준 모두에서 개선되고, last.pt 기준 CI 가 0 을 넘지 않는다.
2. **hydro 는 명확히 해롭다.** 두 기준 모두 악화, last.pt 에서 −0.093. 저장소가
   이미 되돌린 판단이 재확인됐다. 더 볼 필요 없다.
3. **수동 라벨 수정의 Dice 효과는 이 설정으로 측정할 수 없다.** train 78명 중 2명
   (전체 프레임 2.9%)만 고친 변경이라, 애초에 재현성 바닥보다 작은 크기다.
   라벨이 좋아졌다는 근거는 Dice 가 아니라 §3·§4 에 있다.

## 6. 다음에 해야 할 것

* **batch_A / batch_B 검토를 끝낼 것.** VERDICTS.csv 는 110명 중 29명만 덮는다.
  `batch_A/verdicts.csv` 와 `batch_B/verdicts.csv` 는 아직 비어 있어 49명은 아무도
  보지 않았다. §5.1 이 5명으로 낸 효과이므로, 여기가 가장 큰 미개봉 지렛대다.
* **모델 선택을 고치기 전에는 어떤 데이터 실험도 ±0.03 미만을 해결하지 못한다.**
  조기 종료(patience 10) + 다중 시드 평균이 최소 조건이다. 지금은 40 epoch 중
  33 epoch 이 과적합에 쓰이고, 그 안에서 어느 지점이 뽑히느냐가 실험 결과를 정한다.
* **P033 f73~f108 재작업.** §3 참조.
