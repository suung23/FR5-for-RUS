










# Figure and table source map

Every number in `HoLEP_Force_Control_Extended_Abstract.docx` traces to a file in
this repository. Nothing is transcribed by hand: the figures are generated from
the capture logs and the tables are read from the analysis outputs. Rerunning
the analysis changes the figures and the numbers together.

## Regeneration

```bash
python3 extended_abstract/make_fig1.py     # Figure 1  (schematic)
python3 extended_abstract/make_fig2.py     # Figure 2  (from runs/*.csv)
python3 extended_abstract/make_docx.py     # document
soffice --headless --convert-to pdf HoLEP_Force_Control_Extended_Abstract.docx
```

Figure 3 is cropped once from an existing asset (see below) and is not
regenerated by these scripts.

**Caveats recorded in the study report and carried into the text**

- The comparison is on the **probe normal force**, measured while pressing
  near-axially onto the scale. The controlled quantity in the rest of the
  document is the magnitude ‖F‖; the two coincide in this geometry but are not
  the same quantity in general.
- The reference uncertainty is **not subtracted** from the robot–scale residual;
  it is reported alongside it.
- Gravity-compensation residual versus pose order gives Spearman rho = +0.896
  (p < 0.0001) — a systematic component, so the standard deviation understates
  what a single pose can be off by. Not stated in the extended abstract for
  space; **worth adding if a reviewer asks how the 0.182 N was obtained.**
- The scale study was recorded 2026-08-28; the force-holding runs were recorded
  2026-09-02. Whether the same calibration profile was loaded for both is not
  recorded. **[TO BE CONFIRMED]**

## Claims deliberately excluded

- Image-guided orientation control and bladder-lumen segmentation (absent from
  the control stack — see Figure 1 note).
- Any trained or evaluated learning policy.
- Any bladder-phantom result. The phantom used is an abdominal volume phantom
  and **no ultrasound was acquired during the force runs**
  (`force_hold_validation/fh/capture.py` subscribes to wrench, mode, calibration
  and pose only).
- Verification of the forced-retreat mechanism at its threshold: peak force
  reached 4.41 N against a 5.0 N limit, so the mechanism was never triggered.
- Any counterfactual of the form "without the robot the force would have reached
  N newtons". The open-loop runs available give 0.17–0.25 N per 150 mL and the
  stiffness fit failed, so no such statement is supportable.
