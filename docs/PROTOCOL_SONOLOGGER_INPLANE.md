# 시험 계획 — Sonologger 면내 학습이 규칙 기반만큼 하는가

2026-09-14 작성. `EVAL_PLAN_POLICY_RESCUE.md` 의 후속이고, 그 계획의 조건 구성을 이어받되
**묻는 것이 달라졌다.**

> **조작자가 방광을 찾지 못한 자세에서, Sonologger 프리핸드 데이터로 학습한 면내 정책이
> 규칙 기반 제어기만큼 진단 가능한 뷰를 얻어내는가.**

두 실행으로 나눠 돈다. **A**(규칙 기반, 이미 `runs/main_rule` 에 5 자세분이 있다)와
**B**(Sonologger 학습이 붙은 뒤). 두 실행을 **같은 자로** 봐야 하므로, 이 문서의 절반은
"무엇을 고정하는가" 다.

---

## 1. 왜 면내인가 — 범위를 먼저 못 박는다

2026-09-14 확정:

* **면외(단축) 방향은 단일 2D 프레임에서 구조적으로 관측 불가능하다.** 프리핸드에서
  면외 방향과 영상의 상관 ρ = −0.026, 거울 검사 52.4 % (우연). 2D 한 장은 ±면외 기울임에
  대칭이라 센서를 더 좋게 해도 풀리지 않는다. **학습으로 풀 대상이 아니다.**
* **면내는 관측 가능했는데 선택 단계에서 지워졌다.** 관성 보너스가 후보 간 Q̂ 격차의
  **75 배**였고 `decided_frac` 이 **0.0 %** 였다 — Q̂ 가 방향을 정한 적이 한 번도 없다.

Sonologger 면내 학습은 **후자**를 겨냥한다. 따라서 평가 지표도 면내로 잡는다 (§4).
면외 탐색은 두 조건 모두 규칙 기반 훑기가 담당하며, 비교 대상이 아니다.

## 2. 고정해야 할 것 — 하나라도 바뀌면 두 실행을 같은 자로 못 본다

`configs/experiment_freeze.json` 에 값으로 박아 두었고, **세션 시작 전에 반드시**

## 3. 설계

### 자세

**최소 6 자세, 권장 8.** 5 자세로는 짝지은 검정에서 `p < 0.05` 가 **구조적으로 불가능**하다
(McNemar 의 이산성 — 5 쌍 전부가 한쪽으로 가도 양측 p = 0.0625). 6 자세면 전승 시
**p = 0.031** 로 내려간다. 자세를 늘리는 것이 비용 대비 효과가 가장 크다.

자세는 `EVAL_PLAN_POLICY_RESCUE.md` §3 의 시작 조건(면적비 < 2 %, `Q_raw` ≥ 0.6)을 만족하는
"teleop 이 못 찾은 자리" 로 만들고, **관절각을 기록해 두 실행에서 재사용**한다.

### 조건

| 조건 | 실행 A (`runs/main_rule`, 5 자세 완료) | 실행 B (Sonologger) |
|---|---|---|
| `hold` | ● 1/5 성공 | ● **필수** |
| `rule` | ● 5/5 | ● **필수** |
| `search` | ● 4/5 | ○ 선택 (A 와의 완전 대응을 원하면) |
| `policy` | — | ● Sonologger 체크포인트 |

**`policy` 는 `rule` 을 대체하지 않고 나란히 들어간다.** 그래야 같은 세션·같은 자세에서
"학습 기반이 규칙 기반만큼 하는가" 를 짝지어 물을 수 있다. 세션이 다르면 젤·팬텀·조작자가
달라져 짝이 깨진다. **`hold` 는 두 실행 공통 대조군이라 반드시 유지**한다 — 두 실행을 잇는
유일한 공통 축이다.

조건 순서는 자세마다 무작위화한다 (`--seed` 로 재현).

## 4. 지표

### 1차 (사전 등록)

**획득 성공률** — 90 초 안에 진단 가능 뷰(§2 의 세 조건, 연속 3 s)에 도달한 비율.
짝지은 McNemar 정확검정 + 부트스트랩 95 % CI.

### 1차 보조 — 면내 방향 (이 시험의 고유 지표)

학습이 겨냥한 것이 면내 방향이므로, **성공률만으로는 무엇이 좋아졌는지 알 수 없다.**

| 지표 | 정의 | 오늘의 기준선 |
|---|---|---|
| **면내 상관** | **정렬 국면**의 `centroid_dx` 와 정렬축 지령의 상관 (부호를 뒤집어 +1 = 옳음) | 정책 **+0.178** · 규칙 **+1.00** (`inplane_metric.py` 재현값: 규칙 **+0.820**, 범위 +0.53…+0.89) |
| **거울 검사** | Q̂ 가 A 와 −A 중 실제로 뷰를 좋게 한 쪽을 고른 비율 | 면외 52.4 % (우연) |
| `decided_frac` | 관성 보너스보다 Q̂ 격차가 큰 비율 — Q̂ 가 방향을 정한 몫 | **0.0 %** |

`decided_frac` 이 0 이면 성공률이 올라가도 **그 공은 학습이 아니다.** 반드시 함께 보고한다.

### 2차

획득까지 걸린 시간(생존분석), 방광 가시 시간 비율, 최종 면적비, 프로브 회전 총량,
접촉력 밴드 유지율·한계 초과·후퇴 발동, `f_bar` 궤적.

## 6. 실행 명령

**러너는 `scripts/start_policy_eval.sh` 로 띄운다.** `run_experiment.py` 를 직접 부르면
**힘 탐색(`force_search`)이 빠진다** — 그러면 힘 설정값이 출발값에 고정돼 다른 조건이 된다
(`EVAL_PLAN_POLICY_RESCUE.md` 부록 A3). 두 줄을 따로 띄우지 말고 이 스크립트 하나로 띄운다.

**`--out` 에 시각을 붙이지 않는다.** 끊긴 세션을 같은 폴더로 **이어서** 하기 때문이다.
이어받으려면 그 폴더를 `mv` 하지 말고 그대로 두고 같은 명령을 다시 부른다.

```bash
# 시작 전 (5 초)
cd ~/FR5-for-RUS/policy_learning && python3 scripts/preflight_freeze.py

# 세션 (이어받기 포함)
~/FR5-for-RUS/scripts/start_policy_eval.sh \
        --main 8 --conditions rule,hold,search --duration 120 \
        --out ~/FR5-for-RUS/policy_learning/runs/main_rule \
        -- --axes all \
           --frame-map ~/FR5-for-RUS/policy_learning/runs/frame_map.json \
           --gains ~/FR5-for-RUS/policy_learning/runs/probe_rot/attempt_001/axis_gains.json \
           --rule-find-axes thx,thy,y \
           --rule-find-range-deg 12 --rule-find-range-mm 25 \
           --rule-oop-scale 0.5 --rule-align-max-deg 6 \
           --rule-refine-cooldown-s 5 \
           --save-frames --max-saved-frames 1500
```

정책 조건을 붙일 때는 `append_condition.py` 로 계획에 넣은 뒤 `--conditions` 에 `policy` 를
더하고 `--ckpt` 로 체크포인트를 준다.

> ⚠️ **면내 상관은 정렬 국면에서만 재야 한다.** 규칙 제어기는 '찾기' 동안 면외 축을 훑으므로
> 에피소드 전체를 뭉치면 정렬과 무관한 지령이 상관을 희석한다 — 같은 데이터에서 전체 **+0.21**
> 대 정렬만 **+0.82** 였다. `inplane_metric.py` 가 `rule_phase == '유지'` 로 거른다.

`--seed 0` 을 두 실행에서 같게 두면 조건 순서가 재현된다. `session.json` 에 체크포인트
경로가 남고, 에피소드마다 `meta.json` 의 `scale` 절에 U-Net id·`AREA_FULL`·`q_good_enough`
가 남는다 (2026-09-14 추가) — 사후에 "그때 무엇으로 쟀는가" 를 물을 수 있다.

## 7. 무엇이 나오면 주장을 접는가

* `policy` 가 `hold` 와 구별되지 않으면 → 학습이 기여하지 않았다.
* `policy` 가 `rule` 보다 유의하게 나쁘면 → 규칙 기반을 대체할 근거가 없다. (동등이면 충분하다 —
  주장은 "대체 가능" 이지 "우월" 이 아니다.)
* `decided_frac` 이 여전히 0 이면 → 성공률과 무관하게 **Q̂ 가 방향을 정하지 않았다.**
  관성 보너스(`--gamma`)를 낮춰 다시 재야 한다.
* 프리플라이트가 통과하지 못한 세션 → 비교에서 제외한다. 결과가 좋아도 마찬가지다.

## 8. 한계 (결과와 함께 보고할 것)

1. 팬텀 하나, 조작자 하나. 팬텀 간 일반화는 주장하지 않는다.
2. 시연 데이터는 **팬텀 A**(C10UR), 평가는 **다이나믹 팬텀**이다. 분포 이동이 있다.
3. 면외는 두 조건 모두 규칙 기반 훑기가 한다 — 비교 대상이 아니다 (§1).
4. 8 자세라도 검정력은 큰 효과(대략 rule 75 % 대 policy 25 %)에만 민감하다.
