# ±d 패리티 검사

**묻는 것:** elevational 오프셋의 **부호**가 초음파 영상에서 구별되는가.

**왜 중요한가:** 구별되지 않으면 `docs/POLICY_LEARNING_MATH.md` §3.3의 `Q̂` 모드 선택이
성립하지 않고, policy가 elevational 축에서 정지합니다. `docs/IMAGE_SERVOING_MATH.md`
§6 명제 4가 그 조건을 규정합니다 — 거울대칭이면 `o(+d) = o(−d)`이고, 그러면
**어떤 함수를 써도** 부호를 뽑을 수 없습니다.

```
python3 parity_check.py --manifest ~/datasets/pfus/manifest.csv
```

### 결론: **판정 불가** (대칭의 증거가 아님)

검사의 전제가 이 데이터에서 성립하지 않습니다:

1. **elevational 스윕이 없습니다.** PFUS는 임상 프리핸드 스캔이고, 소노그래퍼가 방광을
   찾아 유지합니다. 면적이 clip 전체에서 중앙값 26% 변하지만 그게 면외 이동 때문인지
   압입·변형 때문인지 구분할 수단이 없습니다 (`IMAGE_SERVOING_MATH.md` §4.3).
2. **자세 측정이 없습니다.** 면적으로 `|d|`를 짝짓는 것이 유효하려면 면적이 `d`에
   지배되어야 하는데 확인 불가입니다.
3. 따라서 "면적 peak의 양쪽"이 elevational 최적점의 양쪽이라는 보장이 없습니다.

### ⚠️ 위약 대조 없이는 틀린 결론이 나옵니다

첫 시행에서 부호 일관성이 **cross 1.00 대 대조 0.62**로 나와 "비대칭 확인됨"으로 보였습니다.
위약(임의 지점을 가짜 peak로)에서 **1.00**이 나오면서 뒤집혔습니다.

원인은 대조군 설계 결함이었습니다 — 같은 쪽 대조 쌍이 시퀀스 끝에서 잘려 **작은 간격에
편중**됐고, cross 쌍은 큰 간격까지 포함했습니다. 실제 신호는 centroid의 단조 표류
(`|ρ(cx, idx)| ≈ 0.65`)였고 peak와 무관했습니다.

**이 종류의 주장에는 위약 대조를 항상 붙이십시오.**

### 부수적으로 확인된 것

- **`border_penalty` 항이 이 데이터셋에서 무력합니다** — 20명 전원 경계 접촉비 0.000.
  방광이 화면 경계에 한 번도 닿지 않습니다. `Q_seg` 항 타당성(DESIGN_NOTES §14.2-2)의
  구체적 항목입니다.
- **centroid가 인덱스에 대해 단조 표류합니다** (`|ρ| ≈ 0.65`). `Q_seg`의
  `centroid_stability`가 이 정상 표류를 불안정으로 읽고 있을 수 있습니다.
- **이 데이터셋으로는 `Q̂`도 sign 헤드도 학습할 수 없습니다.** 오프셋 공간이 안 덮여 있습니다.

## 제대로 답하려면

**로봇 제어 하 elevational 스윕**(FK 라벨, <0.1 mm)이 필요합니다. 그러면 면적으로 짝지을
필요 없이 `d`를 직접 알므로 검사가 정확해집니다. `IMAGE_SERVOING_MATH.md` §11-4 스윕
프로토콜이 그것이며, 같은 데이터가 `Q̂` 학습에도 쓰입니다.
