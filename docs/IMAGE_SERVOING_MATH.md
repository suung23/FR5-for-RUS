## 1. 왜 카메라 IBVS를 그대로 못 쓰는가

카메라는 3D를 2D로 **투영**합니다. 장면의 물질점 `X`는 움직여도 여전히 영상에 있고, 추적하는 특징점은 물질점입니다. 그래서 강체 속도관계를 바로 미분하면 상호작용 행렬이 나옵니다.

초음파 프로브는 3D를 2D로 **절단**합니다. 영상은 평면 `Π`와 조직의 교집합입니다. 여기서 나오는 두 가지 결과가 전부를 지배합니다:

1. **추적하는 윤곽점은 물질점이 아닙니다.** 프로브가 움직이면 윤곽점은 조직 표면 위를 *미끄러집니다*. 강체 속도관계를 그대로 쓸 수 없고, **표면 구속조건**을 함께 풀어야 합니다 (§3).
2. **평면을 평면 안에서 움직이는 운동은 정보를 만들지 않습니다.** 같은 해부 단면이 재프레이밍될 뿐입니다. 반대로 평면을 평면 밖으로 옮기는 운동은 *다른 조직*을 보게 만들며, 그 변화량은 보이지 않는 3D 형상에 의존합니다.

(2)를 정확히 진술하는 것이 §2입니다.

## 2. SE(3)의 분해 — 면내/면외 ✅

DESIGN_NOTES §4.1 좌표계:

```
probe:  +x = lateral (배열 방향, 영상면 내 수평)
        +y = elevational (영상면 밖, 슬라이스 두께 방향)
        +z = depth (조직 침투, 영상면 내 수직)
image plane  Π = { y_probe = 0 }
```

> **그림 중심 해설은 [`FRAMES_AND_SE2.md`](FRAMES_AND_SE2.md)** — 이 절의 내용을 그림 다섯 장으로 풀어 둔 문서입니다.
> 브라우저 판은 [`frames_se2.html`](frames_se2.html) (자립형, 외부 요청 없음).

![프로브 프레임과 영상면](figures/10-probe-frames.svg)

*그림 1. 원점은 접촉면 중심. 영상면 `Π`는 `x`–`z` 평면이며 프로브에 강체로 붙어 있습니다. 옅은 점선 두 장은 유한한 슬라이스 두께 — 영상은 수학적 평면이 아니라 두께 2–5 mm짜리 판의 적분이고, §8의 스페클이 이 두께를 이용합니다.*

`Π`를 **집합으로서 불변으로 두는** SE(3) 부분군을 구합니다. 강체변환 `(R, t)`가 평면 `y=0`을 자기 자신으로 보내려면 `y`축(평면 법선)이 보존되어야 하고 `t`의 `y`성분이 0이어야 합니다. 무한소로:

```
Stab(Π) = { g ∈ SE(3) : g·Π = Π }
𝔰𝔱𝔞𝔟(Π) = span{ v_x , v_z , ω_y }        (3차원)
```

동차행렬로 풀면 구조가 즉시 드러납니다 — **`y`에 해당하는 행과 열이 통째로 항등으로 얼어붙고**, 남는 자리가 정확히 SE(2)입니다:

```
      ⎡ cos θ    0    sin θ  │  t_x ⎤   ← x
g  =  ⎢   0      1      0    │   0  ⎥   ← y  (항등으로 고정)
      ⎢ −sin θ   0    cos θ  │  t_z ⎥   ← z
      ⎣   0      0      0    │   1  ⎦
            ↑      ↑      ↑      ↑
            x      y      z      t
                (고정)

자유 성분 3개 — 회전 θ 하나, 병진 t_x·t_z 둘
```

![SE(2) 안정자 부분군의 행렬 형태](figures/13-se2-stabilizer.svg)

*그림 2. `g·Π = Π`의 대수적 내용. 리 대수로 쓰면 생성원이 그대로 나옵니다:*

```
𝔰𝔱𝔞𝔟(Π) = span{ ∂/∂x ,  ∂/∂z ,  x ∂/∂z − z ∂/∂x }
                  v_x      v_z           ω_y
```

세 번째 생성원이 만드는 평면 속도장 `w = (−v_x − ω_y z, −v_z + ω_y x)`가 **표면 법선 `n`을 전혀 포함하지 않는다**는 점이 §4.1의 전부입니다.

나머지 3차원

```
Off(Π) = span{ v_y , ω_x , ω_z }
```

는 평면을 자기 자신 밖으로 옮깁니다.

> **정리 1.** `Stab(Π)` 운동에서 영상은 *동일한 해부 단면*의 2D 강체변환이다. `Off(Π)` 운동에서 영상은 *다른 해부 단면*이 되며, 그 변화는 영상면 밖의 3D 형상에 의존한다.

![여섯 자유도의 면내/면외 분류](figures/12-dof-inplane-outplane.svg)

*그림 3. 점선은 원래 평면, 실선은 운동 후. 윗줄은 둘이 겹칩니다 — 평면은 제자리고 내용만 움직입니다. 아랫줄은 평면 자체가 옮겨갑니다.*

**여기서 첫 번째 실질적 발견이 나옵니다.** DESIGN_NOTES §5의 축 분담을 이 분해에 겹치면:

| 축 | 면내/면외 | 제어원 (§5) |
|---|---|---|
| `v_x` | **면내** | 영상 policy |
| `v_z` | **면내** | admittance (법선력) |
| `ω_y` | **면내** | 아날리틱 (`M_y → 0`) |
| `v_y` | **면외** | 영상 policy |
| `ω_x` | **면외** | 아날리틱 (`M_x → 0`) |
| `ω_z` | **면외** | 영상 policy |

영상 policy는 **면내 1축 + 면외 2축**을 받았습니다. 영상 관측성이 완벽한 두 축(`v_z`, `ω_y`)은 힘 루프에 갔고, policy는 영상이 1차 정보를 주지 않는 두 축을 배정받았습니다.

이 배분 자체는 §5.1의 논거(모멘트가 자세 오정렬을 모호함 없이 측정한다)로 정당합니다 — 물리적으로 옳습니다. 다만 **"policy가 맡은 3축이 다 비슷한 난이도"라는 암묵적 전제가 틀렸다**는 점을 설계에 반영해야 합니다.

## 2.1 `Off(Π)`는 부분군이 아닙니다 ⚠️

대칭성 때문에 면외 셋도 부분군일 것 같지만 아닙니다. `Stab(Π)`는 진짜 부분군입니다 — 평면을 지키는 두 운동을 이어 붙이면 여전히 지킵니다. 면외 셋은 **여집합일 뿐 닫혀 있지 않습니다**:

```
[ ω_x , ω_z ]  =  − ω_y  ∈  𝔰𝔱𝔞𝔟(Π)                                   (2.1)
```

면외 생성원 둘의 괄호가 **면내로 떨어집니다.** 팬(`ω_x`)과 프로브 회전(`ω_z`)을 순서만 바꿔 실행하면 결과가 다르고, 그 차이가 영상면 내 롤입니다.

![면외 생성원의 교환자는 면내 롤이 된다](figures/14-commutator.svg)

*그림 4. 두 경로는 같은 평면에서 끝나지만 내용의 롤이 다릅니다.*

⚠️ **실제 함의.** 힘 루프가 `ω_x`를, policy가 `ω_z`를 동시에 움직이는 이 설계에서 (2.1)은 **실제로 일어납니다** — 두 축이 함께 돌면 지령하지 않은 영상 롤이 생깁니다. 다행히 `ω_y`도 힘 루프가 쥐고 있어 자세 정렬이 그것을 되돌리지만, **policy 입장에서는 자기가 낸 `ω_z`가 영상 롤로 새는 것으로 보입니다.**

🟡 §7(c)의 policy 입력 정상화에서 (7.2)로 워핑해 제거할 대상에 **`ω_x`·`ω_z` 교차항이 만드는 `ω_y` 성분을 포함**시켜야 합니다. 지령 twist를 알고 있으므로 (2.1)로 예측 가능하며, 연산량은 추가되지 않습니다.

이 비대칭 — 면내는 대수적으로 닫힌 구조를 갖고 면외는 갖지 못한다 — 이 두 블록의 제어 난이도가 갈라지는 뿌리입니다.

## 3. 절단 곡선의 운동학 — 표면 구속으로부터 유도 ✅

조직 표면을 세계좌표 고정 음함수 `F(X) = 0`, 단위 법선 `n = ∇F/|∇F|`로 둡니다. 프로브 프레임에서 본 표면의 **겉보기 속도장**은, 프로브 twist `(v, ω)`(probe 프레임 표현)에 대해

```
U(X) = − v − ω × X                                                    (3.1)
```

영상 평면 안의 점 `X = (x, 0, z)`에 대해 (3.1)을 성분으로 풀면 — `ω×X = (ω_y z, ω_z x − ω_x z, −ω_y x)` 이므로

```
U_x = − v_x − ω_y z
U_y = − v_y − ω_z x + ω_x z                                           (3.2)
U_z = − v_z + ω_y x
```

관측되는 윤곽점은 (a) 표면 위에 머물고 (b) 평면 `y=0` 안에 머뭅니다. 평면 내 속도를 `w = (ẋ, ż)`라 하면 `F`의 물질미분 `∂F/∂t = −∇F·U`와 `dF(X_obs, t)/dt = 0`으로부터

```
n_x ẋ + n_z ż = n · U                                                 (3.3)
```

**미지수 2개, 방정식 1개** — 이것이 초음파판 **개구(aperture) 문제**입니다. 윤곽점 하나만으로는 그 점의 이동을 결정할 수 없고, 윤곽 법선 성분만 관측 가능합니다. → **점 특징이 아니라 영역 적분(모멘트)을 써야 하는 이유**이며, `ControlState`가 centroid/area/2차축을 내보내는 것은 이 관점에서 옳은 선택입니다.

평면 내 윤곽 법선 `n_c = (n_x, n_z)/c`, `c := √(n_x²+n_z²) = √(1−n_y²)` 로 두면 (3.3)은

```
w · n_c = ( n_x U_x + n_y U_y + n_z U_z ) / c                         (3.4)
```

**핵심 정의 — 면외 경사도(elevational obliquity):**

```
κ  :=  n_y / √(1 − n_y²)  =  tan θ_out                                (3.5)
```

`θ_out` = 표면 법선이 영상면에서 기울어진 각. `κ = 0` ⟺ 표면이 영상면과 직교 ⟺ 그 지점에서 단면이 elevational 방향의 **극값(정상단면)**.

## 4. 모멘트 상호작용 행렬 ✅

세그멘테이션 영역 `S`, 윤곽 `C`. 모멘트 `m_ij = ∬_S xⁱ zʲ dA`.
Reynolds 수송정리(= 평면에서의 Green 정리)로

```
ṁ_ij = ∮_C xⁱ zʲ (w · n_c) dl                                        (4.1)
```

(3.4)를 대입하고 면내/면외로 가릅니다.

### 4.1 면내 블록 — 정확하고 상수 ✅

⚠️ **주의 — (3.3)은 `w`를 결정하지 않습니다.** 미지수 2개에 방정식 1개이므로 접선 성분은 끝까지 미정입니다 (§3의 개구 문제). 면내 블록이 형상 무관해지는 근거는 (3.3)이 아니라 **정리 1**입니다: 면내 운동에서 영상 평면은 공간에서 같은 평면이고, 그 안의 내용은 강체장

```
w_ip = (U_x, U_z) = (− v_x − ω_y z ,  − v_z + ω_y x)
```

로 **정확히 수송**됩니다. 영역 `S`가 이 장을 따라 이동하므로 (4.1)에 대입하고 발산정리로 되돌리면 `n`이 소거됩니다 — 적분 안에는 `n`이 남지만 적분 결과에는 남지 않습니다. **미지 형상 의존이 없습니다.**

발산정리로 되돌리면 (`∇·w_ip = 0`, 강체장):

```
ṁ_ij |_in = − i·v_x·m_{i−1,j} − i·ω_y·m_{i−1,j+1}
            − j·v_z·m_{i,j−1} + j·ω_y·m_{i+1,j−1}                     (4.2)
```

주요 특징에 대해 풀어쓰면:

| 특징 | 면내 상호작용 |
|---|---|
| 면적 `m₀₀` | `ṁ₀₀ = 0` — **면내 운동은 면적을 보존** |
| centroid `x_g` | `ẋ_g = − v_x − ω_y z_g` |
| centroid `z_g` | `ż_g = − v_z + ω_y x_g` |
| 방위 `θ` (2차 모멘트) | `θ̇ = ω_y` — **1:1 정확** |
| 중심 2차모멘트 `μ₂₀,μ₀₂,μ₁₁` | 병진 불변, `ω_y`에 대해 순수 회전 |

픽셀 좌표 `(u, v)`로 옮깁니다. ⚠️ **여기서 원점은 `ControlState`의 `COORDINATE_CONVENTION`(좌상단)이 아니라 프로브 원점의 영상면 투영 = 배열 중심·접촉면**입니다. 좌상단 기준값 `(u_tl, v_tl)`과는 `u = u_tl − u₀`, `v = v_tl − v₀`로 이어지며, `(u₀, v₀)`는 US 영상 기하에서 나오는 상수입니다 (⏳ §11-1과 함께 확정). `u` 우측, `v` 하측, 등방 스케일 `s` [mm/px]. centroid 상호작용 행렬은

```
⎡u̇_g⎤   ⎡ −1/s    0     −v_g ⎤ ⎡ v_x ⎤
⎢   ⎥ = ⎢                     ⎥ ⎢ v_z ⎥                               (4.3)
⎣v̇_g⎦   ⎣  0    −1/s     u_g ⎦ ⎣ ω_y ⎦
```

![영상면과 픽셀 좌표의 대응](figures/11-image-pixels.svg)

*그림 5. (4.3)이 요구하는 원점은 `ControlState`의 좌상단이 아니라 배열 중심의 투영입니다. 혼동하면 회전 항 `−ω_y·v`가 통째로 틀립니다.*

> **정리 2 (계측성).** (4.3)에는 미지 깊이가 없다. 카메라 IBVS의 `L_p = [−1/Z, 0, u/Z; …]`와 달리 초음파는 **계량(metric) 모달리티**이며, `s`는 음속 1540 m/s와 스캔 기하로 결정되는 **알려진 상수**다.

**따라서 `v_x` 축은 학습이 필요 없습니다.**

```
v_x =  λ · s · (u_g − u*)          λ > 0                              (4.4)
```

`ω_y` 성분을 무시하면 폐루프는 `ė = −λ e`. `ω_y`가 힘 루프에서 들어오더라도 (4.3)의 셋째 열로 **정확히 예측 가능한 외란**이므로 전향보상됩니다:

```
v_x = λ·s·(u_g − u*) − ω_y^cmd · s · v_g                              (4.5)
```

🟡 **제안: `v_x`를 policy에서 빼고 (4.5)의 해석적 법칙으로 고정하십시오.** policy 차원이 3 → 2로 줄고, 남는 2축이 진짜 어려운 축이라는 사실이 드러납니다.

### 4.2 면외 블록 — `κ`가 모든 것을 결정 ⚠️

(3.4)의 `n_y U_y / c` 항이 면외 기여입니다. (3.2)와 (3.5)로

```
ṁ_ij |_out = − ∮_C xⁱ zʲ · κ(l) · ( v_y + ω_z·x − ω_x·z ) dl          (4.6)
```

**모든 기하 모멘트의 면외 열이 `κ`로 게이팅됩니다.** `i, j`를 무엇으로 고르든(면적, centroid, 2차 모멘트) 마찬가지입니다 — `κ`는 특징 정의가 아니라 기하에서 나오기 때문입니다.

⚠️ **이 결과를 `Q_seg` 전체로 확장하면 안 됩니다.** `Q_seg`의 8개 항 중 `mask_completeness`·`component_quality`는 기하 모멘트 계열이라 (4.6)이 적용되지만, `segmentation_confidence`·`lumen_contrast`·`border_penalty`는 **강도(intensity) 기반**입니다. 강도 항은 면외 운동에 대해 영상 *외관*을 통해 반응하며 — 예: elevational로 벗어나면 방광이 아니라 장관 가스가 들어와 대비가 붕괴 — **1차 민감도를 가질 수 있습니다.** 기하가 주지 않는 면외 정보를 외관이 줄 수 있다는 뜻이고, 이것이 §6-3(학습된 비대칭 사전지식)과 같은 이야기입니다. ⏳ §11-4 스윕에서 **항별로** 분리 계측하십시오.

면적(`i=j=0`)의 세 열:

```
∂ṁ₀₀/∂v_y = − ∮ κ dl
∂ṁ₀₀/∂ω_z = − ∮ κ·x dl                                               (4.7)
∂ṁ₀₀/∂ω_x = + ∮ κ·z dl
```

### 4.3 이 유도가 기대는 가정 — 위반하면 무엇이 깨지는가 ⚠️

§3–4는 **네 가지 가정** 위에 서 있습니다. 셋은 실제로 위반되며, 그중 하나는 §5의 수치를 삼킬 수 있습니다.

| 가정 | 실제 | 깨지면 |
|---|---|---|
| **A1. 조직이 강체** | ✗ 프로브가 누르면 방광이 변형 | §5의 면적 신호를 **압도할 수 있음** — 아래 |
| **A2. 세그멘테이션 윤곽 = 기하 절단 곡선** | ✗ U-Net 추정치 | `σ_rel`이 분산만이 아니라 **자세 의존 편향**을 포함. 편향은 신호로 위장 |
| **A3. 영역이 FoV 내부에 완전히 포함** | ✗ 큰 방광은 영상 경계에 닿음 | (4.1) Green 정리에 **경계 선분 기여항**이 추가되어 (4.2)·(4.6)이 그대로 성립하지 않음 |
| **A4. 영상 강도가 시점 무관** | ✗ 정반사·이방성·음영은 빔 방향 의존 | 기하 결론은 유지. **강도 기반 특징**의 상호작용은 (4.6) 밖 (§4.2 주의) |

**A1이 가장 위험합니다.** 힘 루프가 `F_n`을 일정히 유지하지만, 프로브가 피부 위를 슬라이딩하면 접촉 패치·조직 강성·기저 해부가 바뀌어 같은 `F_n`에서도 방광 단면적이 변합니다. §5.2가 elevational 오프셋 5 mm에서 기대하는 신호는 `ΔA/A ≈ 1.6 %`인데, **접촉 조건 변화가 만드는 면적 변화는 통상 이보다 큽니다.**

> ⚠️ **따라서 §5의 수치는 "잡음이 `σ_rel`뿐일 때의 상한"입니다.** 실제 사각지대는 변형 결합만큼 더 넓습니다.

🟡 **처방 — 변형 채널을 분리 측정하십시오.** `v_y`를 고정한 채 `F_n*`만 🟡 ±1 N 변조하고 `∂A/∂F_n`을 구합니다. 그러면

```
ΔA_측정  =  (∂A/∂v_y)·Δy  +  (∂A/∂F_n)·ΔF_n  +  잡음
```

에서 둘째 항을 실측된 `∂A/∂F_n`과 admittance가 아는 `ΔF_n`으로 **전향 제거**할 수 있습니다. §11-8에 넣었습니다. 이 보정 없이는 `v_y` 축의 극값탐색이 elevational 기울기가 아니라 **접촉력 기울기를 따라갑니다** — DESIGN_NOTES §6.3이 시간축 항에서 이미 겪은 것과 같은 종류의 오염입니다.

`κ ≡ 0`(정리 3a)과 `∂A/∂F_n ≠ 0`이 동시에 성립하면, `v_y` 축의 유일한 면적 신호가 변형 잡음뿐인 상황이 됩니다. §8의 스페클 오도메트리가 필요한 진짜 이유가 이것입니다 — 스페클 비상관은 **면적과 독립인 물리 채널**입니다.

## 5. 목표점 특이성 ⚠️ — 가장 중요한 결과

### 5.1 정리 — 정확한 진술

먼저 **틀리기 쉬운 진술 하나를 배제합니다.** "목표가 극값이면 `κ ≡ 0`"은 **거짓**입니다. (4.7)에서 면적이 elevational 극값이라는 조건은

```
∂A/∂v_y = − ∮_C κ dl = 0                                              (5.0)
```

즉 **`κ`의 윤곽 적분이 0**이라는 것뿐이며, `κ`가 점마다 0이라는 뜻이 아닙니다. 둘이 일치하는 것은 해부구조가 영상면에 대해 **거울대칭**일 때입니다.

> **정리 3 (목표점 퇴화).**
> **(a)** 목표 단면에서 구조가 영상면에 대해 국소 거울대칭이면 `κ ≡ 0`이고, (4.6)의 **면외 열이 모든 모멘트에 대해 0**이다.
> **(b)** 대칭이 아니면 `∮κ dl = 0`만 성립한다. **고차 모멘트의 면외 열은 살아남을 수 있다** — 예컨대 `∂ṁ₁₀/∂v_y = −∮κx dl`은 일반적으로 0이 아니다.
> 어느 경우든 목표에 접근하면서 면외 블록의 이득은 0으로 수렴한다.

**(b)는 (a)보다 낙관적인 결과입니다.** 방광이 완벽히 대칭이 아니라면 centroid나 2차 모멘트가 면적보다 먼저 elevational 오프셋을 감지합니다. §11-4 스윕이 답해야 할 것이 정확히 이것입니다 — **어느 특징이 `d`에 대해 1차 항을 갖는가.** 면적만 보고 결론 내리지 마십시오.

(a)와 §6의 명제 4는 **같은 원인의 두 얼굴**입니다: 대칭이 관측성을 죽이고 동시에 부호도 죽입니다. 역으로 비대칭은 둘 다 되살립니다. 면외 축 설계 전체가 이 하나의 양 — **목표 단면 근방의 elevational 비대칭** — 에 걸려 있습니다.

면내와의 대비는 그대로 유효합니다. 면내에는 **직접 측정되는 오차**(centroid 편차)와 **상수·가역 야코비안**이 있습니다. 면외에는 측정 가능한 오차가 없고 스칼라 목적함수뿐이므로 기울기를 **탐침으로 추정**해야 하고, 목표 근방 정밀도는 곡률 대 잡음비가 결정합니다. 이득 튜닝의 문제가 아닙니다.

### 5.2 `v_y` — 수치 ⏳

방광을 반지름 `R`의 구로 근사하고 평면이 중심에서 `d`만큼 elevational로 벗어난 경우:

```
A(d) = π(R² − d²)          ΔA/A₀ = − d²/R²                            (5.1)
```

**1차 항이 없습니다.** `d`에 대해 2차입니다. 세그멘테이션 면적의 프레임간 상대잡음을 `σ_rel`라 하면, `k`-시그마 검출 가능한 최소 오프셋:

```
d_min = R · √( k · σ_rel )                                            (5.2)
```

`R = 40 mm`, `k = 3`:

| `σ_rel` (측정 필요 ⏳) | `d_min` |
|---|---|
| 1 % | **6.9 mm** |
| 2 % | **9.8 mm** |
| 5 % | **15.5 mm** |

비교: 볼록 프로브의 elevational 빔폭은 초점에서 **2–5 mm**. 즉 면적 기반 elevational 되먹임은 **물리 분해능보다 2–5배 거친 사각지대**를 갖습니다. `validity.py`의 `max_relative_area_change = 0.50`이 시사하는 잡음 수준이라면 사각지대는 훨씬 더 큽니다.

🟡 **완화 — 시간 평균.** 위 수치는 단일 프레임 기준입니다. 프로브를 정지시키고 `N` 프레임을 평균하면 `σ_rel → σ_rel/√N`이고 (5.2)에 의해

```
d_min ∝ N^(−1/4)
```

30 Hz에서 1 초 정지 관측(`N = 30`)이면 `d_min`이 약 **2.3배** 줄어듭니다: 9.8 mm → **4.2 mm**로, 빔폭 수준에 근접합니다. 지수가 `−1/4`인 것이 핵심입니다 — 2차 신호이므로 평균의 이득이 통상의 `√N`이 아니라 그 제곱근입니다. **즉 "움직이며 연속 서보"보다 "멈추고 측정 → 스텝"의 이산 탐색이 이 축에서 원리적으로 유리합니다.** §5.4의 ESC 처방이 이 구조와 맞물립니다.

⚠️ 단, `σ_rel`이 백색이 아니라 호흡·박동·조직 크리프로 상관되어 있으면 `√N` 이득이 나오지 않습니다. §11-2에서 표준편차만이 아니라 **Allan 편차**를 그려 평균이 실제로 이득을 주는 구간을 확인하십시오.

### 5.3 `ω_z` — 수치 ⚠️

`rz`는 **빔축 피벗**입니다. 평면 안의 점 `x`가 elevational로 `−ω_z x` 만큼 밀립니다 (3.2). 빔축(`x=0`)은 제자리, 측방으로 갈수록 크게 벗어납니다.

반축 `(a, b, c)`인 타원체(`a` = 현재 면내 lateral, `b` = elevational, `c` = depth)를 중심을 지나는 평면으로 자르고 빔축(`z`)에 대해 `φ` 회전하면, 단면은 반축 `(a(φ), c)`의 타원이고

```
a(φ) = a · [ 1 + sin²φ ( a²/b² − 1 ) ]^(−1/2)
A(φ)/A(0) = 1 + (φ²/2)( 1 − a²/b² ) + O(φ⁴)                           (5.3)
```

**여기서도 1차 항이 없습니다.** 그리고 곡률이 **해부학적 이방성 `(1 − a²/b²)`에 비례**합니다.

> **따름정리.** 단면이 원형(`a = b`)이면 `ω_z`는 면적으로 **모든 차수에서 관측 불가능**하다. 구는 어느 방향으로 잘라도 대원이다.

`k = 3`, `σ_rel = 2 %` 검출 임계 `ΔA/A ≥ 6 %`에 필요한 회전각:

| 이방성 `b/a` | 필요 `φ` |
|---|---|
| 1.5 | **±26.6°** |
| 1.2 | **±35.9°** |
| 1.0 | **∞ (불가능)** |

⚠️ **그러나 위 계산은 회전축이 해부구조 중심을 지난다고 가정했습니다.** 실제 회전축은 피부 위 프로브 접촉점을 지나는 빔축이고, 방광 중심은 거기서 벗어나 있습니다. 오정렬을 넣으면 결과가 달라집니다.

구 근사로 정확히 풀립니다. 방광 중심이 프로브 프레임에서 `(x_c, y_c, z_c)`, 회전은 빔축(`z`) 둘레. 회전 후 평면까지 중심의 거리가 `|y_c cos φ − x_c sin φ|`이므로

```
A(φ) = π[ R² − (y_c cos φ − x_c sin φ)² ]
∂A/∂ω_z |φ=0 = 2π · x_c · y_c                                         (5.3b)
```

**(4.6)–(4.7)로도 같은 값이 나옵니다 — 독립 검증 ✅.** 구의 경우 윤곽 위에서 `n_y = d/R`이 **정확히 상수**이므로 `κ = d/√(R²−d²)`도 상수이고,

```
∮κ dl = κ · 2πr = 2πd            (r = √(R²−d²))
∮κx dl = κ · 2πr · x_c = 2πd·x_c
→  ∂A/∂v_y = −2πd  ,  ∂A/∂ω_z = −2πd·x_c
```

`∂A/∂v_y = −2πd`는 (5.1)의 `dA/dd = −2πd`와 정확히 일치합니다. 서로 다른 두 경로로 같은 답이 나오므로 §4의 유도가 검증됩니다.

따라서 `ω_z`의 정확한 판정은 "관측 불가"가 아닙니다:

| 상황 | `ω_z`의 면적 1차 이득 |
|---|---|
| 정렬됨(`x_c=0` 또는 `y_c=0`) + 등방 단면 | **0 — 모든 차수** |
| 정렬됨 + 이방성 `b/a` | **0 — 2차만**, `∝ (1 − a²/b²)`, ±25–35° 필요 |
| 오정렬 `(x_c, y_c)` | **`2π x_c y_c` — 1차, 오정렬 크기에 비례** |

즉 `ω_z`는 **이득이 목표에서 소멸하는 정상적인 서보 축**입니다. 수렴은 하되 종단 정밀도가 잡음에 지배됩니다. 앞선 초안의 "사실상 서보 불가"는 정렬된 경우만 보고 내린 **과잉 진술이었고, 철회합니다.**

⚠️ 다만 (5.3b)는 `v_y` 열과 **정확히 선형종속**입니다: `∂A/∂ω_z = x_c · ∂A/∂v_y`. §5.4가 바로 이것이며, 구 근사에서는 근사가 아니라 **정확히 랭크 1**입니다 — 면적으로 관측 가능한 것은 조합 `(v_y + x_c ω_z)` 하나뿐입니다. 2차 모멘트(장/단축비, 방위)는 이 퇴화를 깨는 후보이나 이방성에 비례하므로, §11-5·11-6에서 실측으로 판정해야 합니다.

⏳ **실측 항목:** 팬텀/실제 방광에서 elevational 대비 lateral 단면 이방성 `b/a`를 측정하십시오. `b/a < 1.2`면 `rz`는 미세 서보가 아니라 **초기 자세 탐색(coarse search)** 축으로 재분류해야 합니다.

### 5.4 `v_y` ↔ `ω_z` 조건수 ⚠️

(4.7)에서 두 열은 `∮κ dl`와 `∮κx dl`입니다. `κ`가 윤곽을 따라 대체로 일정하고 윤곽이 `x_g` 기준 대칭이면

```
∮ κ·x dl  ≈  x_g · ∮ κ dl        →  두 열이 선형종속 (랭크 1)          (5.4)
```

두 축을 구분하려면 **`κ`의 centroid 기준 1차 모멘트** `∮κ(x − x_g)dl ≠ 0`, 즉 해부구조의 면외 경사도가 lateral 방향으로 *변해야* 합니다. 일반적으로 작은 양입니다.

> **예측:** policy는 elevational 슬라이드와 빔축 회전을 혼동합니다. 두 축을 동시에 자유롭게 두면 학습이 수렴하지 않거나, 수렴해도 잘못된 축에 크레딧을 줍니다.

🟡 **처방:** 두 축을 동시에 열지 마십시오.
- **(A) 순차:** `rz` 조대 탐색 → 고정 → `v_y` 미세 탐색. §7의 힘 탐색 2단 구조와 같은 패턴.
- **(B) 직교 dither ESC:** `v_y`를 `f₁`, `ω_z`를 `f₂ ≠ f₁`로 진동시키고 `Q_seg`를 각각 복조. 5 Hz 루프에서 `f₁ = 0.5 Hz`(진폭 🟡 3 mm), `f₂ = 0.3 Hz`(진폭 🟡 5°)면 Nyquist 여유 충분.

## 6. 부호 관측 불가능성 — 단일 프레임 policy의 한계 ⚠️

> **명제 4.** 목표 자세에서 해부구조가 영상면에 대해 국소적으로 거울대칭이면, elevational 오프셋 `+d`와 `−d`에서 얻는 B-mode 영상은 동일하다. 그러나 올바른 행동은 각각 `−d`, `+d`로 **부호가 반대**다. 따라서 **단일 영상에서 올바른 `v_y`로 가는 함수는 존재하지 않는다.**

방광은 목표 단면 근방에서 거울대칭에 가깝습니다 (그래서 그 단면이 극값입니다). 대칭이 곧 목표의 정의이므로 이 문제는 회피할 수 없습니다.

**따라서 policy 입력은 다음 중 최소 하나를 반드시 포함해야 합니다:**

1. **프레임 스택 + 행동 이력** — 자신이 방금 낸 운동과 그에 따른 `Q` 변화로 기울기를 *암묵적으로* 추정. (= 학습된 ESC).
   ⚠️ **정정:** 초안의 🟡 `N ≥ 4`는 너무 짧습니다. §5.4의 dither 주기(2 s)를 한 번 이상 관측해야 하므로 `N ≥ f_us / f₁` — 8 fps·0.5 Hz면 🟡 **`N = 16`**입니다. 유도는 [`POLICY_LEARNING_MATH.md`](POLICY_LEARNING_MATH.md) §1.3.
2. **스페클 비상관 기반 elevational 오도메트리** — §8.
3. **비대칭 사전지식** — 학습이 진짜 값을 더하는 지점. 명제 4는 *기하*가 부호를 못 준다는 것이지, *외관*이 못 준다는 뜻이 아닙니다. 실제 방광은 완전 대칭이 아니고(요관구, 방광삼각, 주변 장기 음영), 학습된 모델은 "8 mm 두측으로 벗어난 방광은 이렇게 보인다"를 알 수 있습니다. **이것이 policy 학습의 유일한 원리적 정당화입니다.**

⚠️ **데이터 수집 요구사항 (§14.3 항목에 추가할 것):** 3이 성립하려면 학습 데이터가 elevational 오프셋 공간을 **의도적으로 스윕**하고 **참값 오프셋을 라벨로 가져야** 합니다. 목표 근방만 모은 데이터로는 학습해도 부호를 알 수 없습니다. 현재 `fr5_h5_collector` 계획에는 이 스윕 프로토콜이 없습니다.

## 7. 면내 플로우 예측 — §14.3의 해소 ✅

(3.2)로부터, **면내 운동이 만드는 광학 플로우장은 닫힌 형태입니다**:

```
ẋ(x, z) = − v_x − ω_y z
ż(x, z) = − v_z + ω_y x                                               (7.1)
```

픽셀 단위 (원점 = 배열 중심 투영, `s` mm/px):

```
Δu(u,v) = − ( v_x/s + ω_y·v ) · Δt
Δv(u,v) = − ( v_z/s − ω_y·u ) · Δt                                    (7.2)
```

세 가지 결과:

**(a) `temporal_warped_iou`용 warp를 공짜로 얻습니다.** §14.3은 "Farneback을 30 Hz 온라인으로 돌려야 하고 그 비용이 지연 예산에 없다"를 미결로 남겨두었습니다. 면내 운동 — 그리고 힘 루프가 만드는 `v_z`, `ω_y` 외란 전부가 면내입니다 — 은 (7.2)로 **지령 twist에서 해석적으로 예측**됩니다. 연산량 0.

**(b) 잔차가 면외 관측량입니다.** 측정 플로우에서 (7.2)를 뺀 잔차는 정의상 면외 운동 + 조직 변형입니다. 순수 elevational 운동은 *일관된 플로우장을 만들지 않고* 스페클을 비상관시키므로, 잔차는 큰 벡터가 아니라 **플로우 신뢰도의 붕괴**로 나타납니다.

`rus_perception/flow/reliability.py`가 이미 정확히 이 신호들을 계산합니다 — docstring에 "out-of-plane motion", "local speckle decorrelation (windowed NCC)"가 명시되어 있습니다. **면외 관측 인프라가 이미 있습니다.** 필요한 것은 이것을 품질 게이트가 아니라 **제어 관측량**으로 승격하는 일입니다.

**(c) policy 입력을 정상화(stationarize)할 수 있습니다.** 힘 루프의 `v_z`, `ω_y`는 policy 입장에서 외란입니다. (7.2)로 미리 워핑해 제거한 뒤 policy에 넣으면, policy가 보는 영상 흐름은 자기 행동의 결과만 남습니다. 🟡 **강력히 권장** — 학습 난이도를 크게 낮춥니다.

🟡 **제안 구현:**
```
predicted_flow = f(twist_cmd, dt, s)        # (7.2), O(HW) 산술, ~0.1 ms
residual_flow  = measured_flow − predicted_flow    # Farneback 필요 시에만
oop_evidence   = 1 − mean(local_ncc(I_t, warp(I_{t−1}, predicted_flow)))
```
`oop_evidence`는 "지령한 면내 운동으로 설명되지 않는 영상 변화량"입니다. **`κ ≈ 0` 판정(= elevational 극값 도달)의 직접적 신호**가 됩니다.

## 8. 스페클 비상관 — 면외 오도메트리 🟡

완전발달 스페클의 elevational 상관은 가우시안으로 잘 근사됩니다:

```
ρ(Δy) = exp( − Δy² / (2 σ_e²) )      σ_e ≈ (elevational 빔폭)/2 ≈ 1–2 mm   (8.1)
```

역으로 `|Δy| = σ_e √(−2 ln ρ)`. `ρ`는 (7.2)로 정렬한 두 프레임의 국소 NCC로 측정합니다 — `reliability.py:_local_ncc`가 이미 계산합니다.

⚠️ **가우시안은 `Δy = 0`에서 기울기가 0입니다** (`dρ/dΔy = −(Δy/σ_e²)ρ`). 즉 스페클도 *아주 작은* 변위에는 둔감하고, 민감도는 `Δy ≈ σ_e` 부근에서 최대입니다. **dither 진폭을 `σ_e` 언저리(🟡 1–2 mm)로 잡아야 하는 정량적 근거**가 여기서 나옵니다 — §5.4의 🟡 3 mm는 이 관점에서도 타당한 범위입니다.

**얻는 것 / 못 얻는 것을 정확히 구분하십시오:**

| | |
|---|---|
| ✅ **얻음** | 프레임간 elevational **변위 크기** `\|Δy\|`. `Δy ~ σ_e` 부근에서 🟡 0.1–0.5 mm 급 (완전발달 스페클 가정, 실조직에서는 열화). ⚠️ 이것은 *상대 변위* 분해능이며 §5.2의 *절대 오프셋* 사각지대와 직접 비교할 수 없습니다 — 앞선 초안의 "10배 정밀" 비교는 철회합니다 |
| ✅ **얻음** | "`v_y`를 지령했는데 실제로 면외로 갔는가" 검증 — 접촉 미끄러짐 / IK 추종 실패 탐지 |
| ✅ **얻음** | dither 진폭 교정 — ESC의 dither가 빔폭 대비 충분한지 실시간 확인 |
| ⚠️ **못 얻음** | **부호.** `ρ`는 `Δy`의 우함수 |
| ⚠️ **못 얻음** | **목표까지의 오차.** 이것은 오도메트리(속도)이지 목표 오차(위치)가 아님 |

부호는 지령 운동 방향에서 옵니다 (로봇이 자기 운동을 압니다). 즉 스페클은 §6의 명제 4를 **해결하지 못하지만**, ESC의 dither를 정량적으로 신뢰할 수 있게 만들어 **탐색을 가능하게** 합니다.

⏳ **`σ_e` 실측:** 프로브를 팬텀에 정지 접촉시키고 `v_y`로 0.2 mm 스텝 스윕하며 `ρ(Δy)` 곡선을 그리십시오. Phase 3 항목. 이 곡선 하나가 elevational 축 설계 전체의 스케일을 결정합니다.

## 9. DESIGN_NOTES 반영 사항 🟡

### 9.1 §4.1의 `rz` 서술 — 오류가 아니라 용어 충돌 🟡

현재:
```
- rz = 영상면 회전
```

이 초안은 처음에 이것을 "틀린 서술"이라고 했는데, **과했습니다. 철회합니다.** "영상면 회전"은 두 가지로 읽힙니다:

- **영상면을 회전** (평면 자체를 공간에서 돌림) → `ω_z`. **원저자의 의도로 보이며 옳습니다.**
- **영상면 안에서 회전** (평면 내용의 롤) → `ω_y`.

시각서보 문헌에서 "image-plane rotation"은 보통 후자를 뜻하므로 오해 소지가 있을 뿐, 설계의 오류가 아닙니다.

🟡 **제안은 문구 명확화뿐입니다:**
```
- rz = 빔축(depth 축) 둘레 피벗. 영상면 자체를 공간에서 회전 → 다른 조직을 자름 (영상면 밖)
- ry = 영상면 내용의 회전 (영상면 안). 힘 루프 소관 — 표면 법선 정렬이 결정
```

`ω_y`가 힘 루프에 있는 것도 물리적으로 옳습니다 — 소노그래퍼도 영상 내 회전을 독립적으로 고르지 않고, 프로브가 피부에 어떻게 앉느냐로 결정됩니다.

### 9.2 §5.3의 대응표를 확장할 것

현행:
```
Q_seg  ←──  면내 축 (x, y, rz)
```

여기서도 **"면내"는 아마 *피부면* 내를 뜻할 것입니다** (§4.1의 "x, y 병진 = 피부 위 슬라이딩"과 일관됩니다). 그렇다면 분류 자체는 맞습니다. 다만 이 문서의 "면내"는 *영상면* 내이므로 두 용법이 충돌하고, 더 중요하게는 **세 축이 같은 난이도라는 인상**을 줍니다. 실제로는 성격이 다릅니다:

```
Q_seg 최대화
  ├─ v_x  : 면내. 1차 오차 회귀. 해석적 (4.5). 학습 불필요        ✅
  ├─ v_y  : 면외. 2차 극값탐색. κ→0에서 특이. ESC + 스페클        ⚠️
  └─ ω_z  : 면외. 2차 극값탐색. 이방성에 비례. 조대 탐색 축        ⚠️
```

### 9.3 §14.3의 플로우 비용 결론을 갱신할 것

"Farneback을 30 Hz 온라인 계산해야 한다"는 결론은 §7(a)에 의해 **면내 성분에 한해 불필요**합니다. 남는 질문은 "잔차 플로우를 실제로 계산할 것인가, 아니면 국소 NCC만으로 충분한가"이며, NCC는 Farneback보다 훨씬 쌉니다.

## 11. 검증 계획 (Phase 3에 추가) ⏳

1. **`s` [mm/px] 확정.** 스캔 기하 + 음속. (4.3)의 유일한 파라미터. `configs/*.yaml`의 `pixel_spacing: 1.0`이 현재 placeholder.
2. **`σ_rel` 측정.** 프로브 정지 접촉, 500 프레임, `mask_area_ratio`의 상대 표준편차. → (5.2)로 `v_y` 사각지대 확정.
3. **면내 상호작용 행렬 검증.** 알려진 `v_x` 스텝(🟡 ±5 mm)을 지령하고 centroid 변위를 측정. (4.3) 예측 대비 오차 <🟡 10% 면 §4.2 툴 변환이 맞다는 뜻이기도 함 (`v_slip = ω × δ` 교차검증).
4. **elevational 스윕.** 접촉 유지한 채 `v_y`를 ±20 mm, 0.5 mm 간격 스윕. 기록: `mask_area_ratio`, `Q_seg`, 국소 NCC. → `A(d)` 곡선(5.1 검증), `ρ(Δy)` 곡선(σ_e 확정), 실제 사각지대.
5. **`rz` 스윕.** `ω_z`로 ±40°, 2° 간격. → 이방성 `b/a` 추정 + (5.3) 검증 + `rz`의 축 분류 결정.
6. **`v_y`/`ω_z` 조건수.** 4·5의 데이터로 `[∂Q/∂v_y, ∂Q/∂ω_z]` 2×2 블록을 수치 구성하고 조건수를 오프셋의 함수로 플롯. (5.4) 검증.
7. **플로우 예측 검증.** 지령 `v_z`/`ω_y` 스텝에 대해 (7.2) 예측 플로우와 Farneback 측정을 비교. 잔차 RMS <🟡 1 px 면 §7(a) 채택.
8. **변형 채널 분리 ⚠️ (§4.3).** `v_y` 고정, `F_n*`만 🟡 ±1 N 변조하여 `∂A/∂F_n`을 측정. **4번보다 먼저 하십시오** — 이 값을 모르면 4번의 `A(d)` 곡선을 해석할 수 없습니다.
9. **비대칭 판정 (정리 3b).** 4번 스윕 데이터에서 면적뿐 아니라 `centroid_y`, `major/minor`, `orientation`, 그리고 `Q_seg` **8개 항 각각**을 `d`에 대해 회귀. **1차 항이 유의한 특징이 하나라도 있는지**가 `v_y` 축 설계의 분기점입니다.

**의존 순서:** 1 → 2 → 8 → 4 → 9 → (5 → 6). 3·7은 US 없이 Phase 0–2에서 병렬 가능.

4·5·6·9는 Phase 6 policy 데이터 수집 프로토콜의 원형이기도 합니다 (§6의 스윕 요구사항).

## 부록 C. 정정 이력 (2026-08-23 자체 재검산)

유도 (3.1)–(4.7)·(5.1)·(5.3)은 재검증 결과 그대로입니다. 정정된 것은 **거기서 끌어낸 결론**입니다.

| # | 초안의 진술 | 정정 |
|---|---|---|
| 1 | "목표에서 `κ ≡ 0`이므로 면외 열 전체가 0" | **거짓.** 극값 조건은 `∮κ dl = 0`뿐. `κ ≡ 0`은 **거울대칭일 때만**. 비대칭이면 고차 모멘트 1차 항이 생존 (정리 3b, §5.1) |
| 2 | "`ω_z`는 면적 신호로 사실상 서보 불가" | **과잉.** 정렬된 경우만 본 결론. 오정렬 시 1차 이득 `2π x_c y_c` (5.3b, §5.3) |
| 3 | "특징을 무엇으로 고르든, 나아가 `Q_seg` 전체가 `κ`로 게이팅" | **과잉일반화.** (4.6)은 기하 모멘트에만 적용. 강도 기반 항은 밖 (§4.2) |
| 4 | "(3.3)이 `w` 전체를 결정한다" | **틀림.** (3.3)은 미지수 2개·식 1개로 접선 성분 미정. 면내 형상 무관성의 근거는 정리 1 (§4.1) |
| 5 | "DESIGN_NOTES §4.1의 `rz` 서술이 틀렸다" | **부당.** "영상면 회전" = "영상면을 회전"으로 읽으면 옳음. "면내"도 *피부면* 내로 읽으면 일관. 용어 충돌일 뿐 (§9.1) |
| 6 | "스페클이 면적 대비 10배 이상 정밀" | **비교 오류.** 상대 변위 분해능 vs 절대 오프셋 사각지대. 비교 불가 (§8) |
| 7 | (4.3)의 픽셀 원점을 "좌상단"이라 서술 | **모순.** 식이 요구하는 원점은 배열 중심 투영. `COORDINATE_CONVENTION`과의 변환 명시 (§4.1) |
| 8 | 강체 조직 가정을 명시하지 않음 | **누락.** 변형이 §5 수치를 압도할 수 있음. §4.3 신설, §11-8 추가 |
| 9 | 단일 프레임 `σ_rel`만으로 사각지대 산정 | **누락.** 시간 평균으로 `d_min ∝ N^(−1/4)`. 9.8 → 4.2 mm (§5.2) |

**독립 검증 하나:** 구 근사에서 (4.6)–(4.7) 경로로 얻은 `∂A/∂v_y = −2πd`가 `A = π(R²−d²)`의 직접 미분 `dA/dd = −2πd`와 일치합니다 (§5.3). 유도의 핵심부가 서로 다른 두 방법으로 확인됩니다.
