단축키

P 다각형: 클릭으로 꼭짓점, Enter 채움, Esc 취소
D 브러시 그리기 / E 지우개, [] 크기
←→ 프레임 이동 (자동 저장)
Tab 다음 미완성 프레임
C 이전 프레임 마스크 복사
N 방광 없음 (빈 마스크 저장)
X 지우고 다시 / Z 되돌리기
Space 마스크 잠깐 숨기기
+- 확대

요령

방광 = 어둡고(무에코) 매끈한 경계 안쪽만. 벽·후방 증강은 제외.
경계가 흐리면 안쪽으로 보수적으로.
같은 자세의 다음 프레임은 C 뒤 손보기.
